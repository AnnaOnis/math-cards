# 📐 Конструктор карточек по математике

Инструмент для учителей математики: превращает текст с заданиями (сгенерированный ИИ) в красиво оформленные печатные карточки с формулами, местом для решения и ключами для проверки.

## 🌐 Как открыть

Перейдите по ссылке:
**https://ваш-логин.github.io/math-cards/](https://annaonis.github.io/math-cards/**

## 🚀 Как пользоваться

1. Откройте [инструкцию](help.html).
2. Скопируйте промпт.
3. Получите задания у любого ИИ (ChatGPT, DeepSeek, Claude, YandexGPT).
4. Вставьте задания и ответы в конструктор.
5. Распечатайте карточки.

## ✨ Возможности

- 1, 2 или 3 карточки на листе A4
- От 0 до 5 строк для решения под каждым заданием
- Корректный рендер дробей и формул через KaTeX
- Автоматическая нумерация заданий и ответов
- Ключи для учителя на отдельной странице
- Печать в PDF в один клик
- Работает на компьютере и телефоне
