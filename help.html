📘 Как пользоваться конструктором карточек

Инструмент работает в 3 шага: получить задания у ИИ → вставить их в конструктор → распечатать карточки.

Шаг 1. Сгенерируйте задания с помощью ИИ

  1. Скопируйте промпт ниже (кнопка «Скопировать»).
  2. Откройте чат с любым ИИ (ChatGPT, DeepSeek, Claude, YandexGPT и т.п.).
  3. Вставьте промпт и заполните параметры: класс, тема, количество вариантов, количество заданий, типы заданий.
  4. Отправьте запрос и дождитесь ответа.

Шаг 2. Вставьте ответ ИИ в конструктор

  1. Откройте конструктор карточек.
  2. Заполните поля: Класс, Тема, Карточек на листе, Строк для решения.
  3. В поле «📝 Задания» вставьте блок с заданиями (до строки «Ответы:»).
  4. В поле «🔑 Ответы» вставьте блок с ответами (начиная со строки «Ответы:»).
  5. Нажмите кнопку «📄 Собрать карточки».

Шаг 3. Распечатайте

  1. Нажмите «🖨️ Распечатать карточки» (или Ctrl+P / Cmd+P).
  2. В диалоге печати выберите: формат A4, поля «По умолчанию» или «Минимальные», отключите «Колонтитулы».
  3. Сохраните в PDF или отправьте на печать.
💡 Совет. Если работаете с телефона, используйте кнопку «Поделиться» → «Печать» в браузере.

📋 Промпт для ИИ (скопируйте и вставьте)

Ты — опытный учитель математики в российской школе, хорошо знающий ФГОС и примерные образовательные программы. Мне нужны задания для печатных карточек по математике. Параметры: - Класс: [указать класс числом] - Тема: [указать тему, например, «сложение, вычитание, умножение натуральных чисел»] - Количество вариантов: [число] - Количество заданий в каждом варианте: [число] - Типы заданий: [указать типы заданий, например: только примеры, только уравнения, примеры и задачи и т.д.] Требования к заданиям: - Задания должны соответствовать возрасту и программе указанного класса. - Типы заданий, количество вариантов и заданий должны строго соответствовать указанным. - В каждом варианте должны быть задания разного уровня сложности (базовые, средние, повышенные) в рамках темы. - Все варианты должны быть примерно равной сложности и не повторяться. - Для каждого задания укажи ответ. Ответ может быть числом, выражением или кратким пояснением (например, "x = 5", "12 км/ч", "20%"). Оформление формул (ВАЖНО!): 1. Все математические выражения записывай с помощью LaTeX-команд БЕЗ пробелов внутри команд. ✅ \frac{x}{3}+2=7 ❌ \frac {x} {3} + 2 = 7 2. НЕ используй разделители \( ... \) и $$ ... $$ — только чистый LaTeX-код. ✅ 2x+5=17 ❌ \(2x+5=17\) 3. Если задание целиком является формулой или уравнением — пиши её как чистый LaTeX. 4. Если задание содержит и текст, и формулу — формула записывается как чистый LaTeX прямо внутри текста, без разделителей. ✅ Турист прошёл \frac{3}{8} маршрута. Сколько км он прошёл, если весь маршрут 40 км? ✅ Вычислите: \frac{5}{7}+\frac{3}{7} 5. Текстовые задачи без математических выражений пиши обычным текстом, без LaTeX. 6. Не используй HTML-теги, Markdown (** или *), таблицы и другие способы форматирования. Формат вывода (строго соблюдай): Сначала выведи задания по вариантам в следующем виде: --- Вариант 1: 1) [задание 1] 2) [задание 2] --- Вариант 2: 1) ... --- После всех вариантов выведи отдельный блок с ответами. Каждый ответ должен быть на новой строке и иметь соответствующий номер задания в варианте: --- Ответы: Вариант 1: 1) x = 6; 2) x = 5; Вариант 2: 1) ...; 2) ...; --- Важно: - Все математические выражения записывай с помощью LaTeX-команд без пробелов внутри команд. - В ответах, если требуется пояснение, пиши после ответа в скобках. - Проверь, чтобы все задания были корректны и решаемы для указанного класса. - Не используй лишних пояснений вне указанных блоков.
